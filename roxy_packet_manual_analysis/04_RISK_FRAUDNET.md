## `GET c6.paypal.com/v1/r/d/b/p3`

URL fields:

| Field | Meaning/use | Source/generation | Static/dynamic | Relation |
| --- | --- | --- | --- | --- |
| `f` | Fraud correlation id. In captures it is BA or EC token. | Current PayPal token from URL/session. | Session dynamic. | Links device fingerprint to checkout/signup token. |
| `s` | Source/app id, e.g. `IWC_NEXT_CHECKOUT` or `CHECKOUTUINODEWEB_ONBOARDING_LITE`. | PayPal JS/flow phase. | Static per phase. | Separates checkout vs onboarding risk context. |

Use: lightweight bootstrap/probe before full FraudNet posts. Often returns image/204/200 or fails silently.

## `POST /v1/r/d/b/p1`

Body top-level: `appId`, `correlationId`, `payload`.

| Field family | Meaning/use | Source/generation | Static/dynamic |
| --- | --- | --- | --- |
| `appId` | Risk app/source id. | PayPal risk JS. | Static per phase. |
| `correlationId` | BA/EC token. | PayPal session. | Session dynamic. |
| `payload.connectionData.*` | Network Information API data: type, effectiveType, rtt, downlink. | Browser APIs. | Device dynamic. |
| `payload.navigator.*` | UA, appVersion, cookieEnabled, language, platform, product, online status. | Browser APIs. | Device dynamic. |
| `payload.screen.*` | Width/height/color depth/pixel depth. | Browser screen APIs. | Device dynamic. |
| `payload.window.*` | Viewport/outer sizes/device pixel ratio. | Browser APIs. | Device dynamic. |
| `payload.tz`, `payload.tzName` | Timezone offset/name. | Browser date/Intl APIs. | Device dynamic. |
| `payload.trt`, `payload.time`, timing subfields | Runtime timing/performance. | JS runtime/performance APIs. | Device/session dynamic. |
| `payload.lst.*` | Local storage/cookie-like risk state. | Browser storage/cookies. | Response/session-derived dynamic. |

Response: risk response JSON, sometimes identical for repeated same browser context, but request remains dynamic.

## `POST /v1/r/d/b/p2`

Body top-level: `appId`, `correlationId`, `payload.URL`, `payload.tnt`, `payload.data`.

| Field family | Meaning/use | Source/generation | Static/dynamic |
| --- | --- | --- | --- |
| `payload.URL` | Current page URL. | Browser location. | Page/session dynamic. |
| `payload.data.plugins[]` | Plugin enumeration, usually PDF plugins. | Browser plugin API. | Device dynamic. |
| `payload.data.cv.*` | Canvas fingerprint and timing. | Canvas JS. | Device/risk dynamic. |
| `payload.data.vm.gpu.vendor/renderer` | WebGL GPU identity. | WebGL JS. | Device dynamic. |
| `payload.data.vm.cores` | CPU core count. | `navigator.hardwareConcurrency`. | Device dynamic. |
| `payload.data.vm.jsMem.*` | JS heap size info. | Performance memory API. | Device dynamic. |
| `payload.data.vm.perfNav.*` | Navigation timing fields. | Navigation Timing API. | Device/page dynamic. |
| `payload.data.vm.timing.*` | Internal fingerprint timings. | JS runtime. | Device/risk dynamic. |

Use: deeper fingerprint after p1. It is generated by PayPal/FraudNet JS, not by static HTML.

## `POST /v1/r/d/b/pa`

Observed body keys emphasize location permission payload:

| Field | Meaning/use | Source/generation | Static/dynamic |
| --- | --- | --- | --- |
| `payload[].loc[].coords.latitude/longitude` | Browser geolocation coordinates or placeholder from geolocation API. | Browser geolocation API. | Device/location dynamic. |
| `payload[].loc[].corrId` | Correlation token. | Current BA/EC token. | Session dynamic. |
| `payload[].loc[].sourceId` | App/source id. | Risk JS. | Static per phase. |
| `locationTime`, `permissionTime` | Timings for location permission/read. | Browser JS. | Device dynamic. |

Use: advanced risk packet. If geolocation is absent/denied, payload shape can still exist with default/empty structures.

## `/v1/r/d/b/w` beacons

Two modes observed:

1. `POST /w` body contains `appId`, `correlationId`, `payload.pkc.*`, `payload.slt`, `payload.uvpat`, `payload.cmat`, `payload.capt`.
2. `GET /w?f=...&s=...&d=...` image beacon contains encoded JSON `d` with `rDT` or field-timing style payload.

| Field | Meaning/use | Source/generation | Static/dynamic |
| --- | --- | --- | --- |
| `pkc.*` | Capability/known-client flags. | Risk JS constants. | Static/risk config. |
| `slt`, `uvpat`, `cmat`, `capt` | Visit/click/session timing values. | JS timers/randomized runtime. | Device/session dynamic. |
| GET `f` | Token correlation. | Current BA/EC token. | Session dynamic. |
| GET `s` | Source app id. | PayPal risk phase. | Static per phase. |
| GET `d.rDT` | Encoded timing/mouse/performance data. | Risk JS runtime. | Device dynamic. |

## DDBM packets

- `GET ddbm2.paypal.com/tags.js`: static script load. Several strict duplicates can be skipped after one representative.
- `POST ddbm2.paypal.com/js/`: dynamic device/behavioral telemetry. Body changes per event/session and should not be skipped as duplicate unless strict fingerprint matches.

Relation: FraudNet/DDBM packets happen immediately after PayPal HTML/JS bootstrap and before/around signup/login/captcha actions. They provide `fn_sync_data` and risk state consumed by `/pay` actions, idapps GraphQL, and `SignUpNewMemberMutation`.
